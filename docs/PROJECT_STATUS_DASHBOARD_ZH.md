## 当前阻塞与风险

1. **尚无真实执行证据。** 当前只确认代码已提交到开发分支的待验证状态；不能声称 TypeScript、测试或构建已通过。
2. **Token 估算是启发式。** \`heuristic-v1\` 不能替代具体模型的 tokenizer。
3. **适配器目前是导出器。** 尚未实现 Cursor / Claude Code 插件、自动文件写入或模型 API 调用。
4. **本地 API 无认证。** 默认仅监听 \`127.0.0.1\`，禁止直接暴露到公网或不可信局域网。
